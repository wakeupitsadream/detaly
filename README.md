# detaly

Платформа перепродажи автозапчастей для Оренбурга: сайт, боты MAX и Telegram, приём оплаты через ЮKassa, заказ у поставщика Rossko, выдача и установка в автосервисе «Сервис56».

Статус: этап планирования завершён, код ещё не написан.

## С чего начать

1. `docs/PLAN.md` — утверждённый поэтапный план: архитектура, модель данных, машина состояний заказа, интеграции (Rossko SOAP, ЮKassa, MAX/Telegram, VIN), UX, фазы с приёмкой, внешние и юридические шаги, риски, бюджет, проверка, первая неделя.
2. `docs/research/research-brief.md` — выверенные факты исследования (API Rossko, VIN-каталоги, 54-ФЗ, АУСН, ЗоЗПП, 152-ФЗ, боты, инфраструктура) с пометками «непроверено» там, где источники из контейнера были недоступны.
3. `docs/research/design-review.md` — итоги панели проектирования и замечания критика; все блокеры и major-пункты учтены в плане.

Фаза 0 начинается с внешних действий (ОКВЭД, аккаунт Rossko и ключи API, домен, РКН, ЮKassa, проверка маркировки) параллельно с каркасом монорепо; два гейта фазы 0 описаны в плане.
