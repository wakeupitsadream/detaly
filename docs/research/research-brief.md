Из контейнера были недоступны все .ru-домены, поэтому первоисточниками подтверждено только то, что видно в открытом коде и официальных схемах (GitHub, PyPI, npm); остальное помечено «непроверено» и требует ручной сверки.

## 1. Rossko и поставщики

У Rossko есть официальный SOAP/WSDL API v2.1 на https://api.rossko.ru/service/v2.1/{Method}?wsdl с авторизацией ключами KEY1/KEY2 из личного кабинета регионального сайта или от менеджера; v1 закрыта (https://github.com/mirikoff/rossko-api-manager). Методы: GetSearch (по артикулу/бренду — цена, остаток, срок и тип предложения по каждому складу, кроссы), GetCheckoutDetails (доставка, оплата, адреса, реквизиты аккаунта), GetCheckout (возвращает orderIds, deliveryCosts, items и itemErrors — часть позиций может не заказаться уже после оплаты клиентом), GetOrders (≤20 заказов за вызов, 16 кодов статусов, включая цепочку возврата 32→36), GetSettlements (баланс, кредитный лимит, просрочка) (https://github.com/tamgdemaslo/vin_oil_mann). Лимиты 300 запросов/мин и 100 000/сутки со сбросом в 00:00 МСК — пересказ документации сторонним клиентом, сверить в ЛК. В API нет поиска по VIN, фото и описаний; OEM-каталог сайта работает на Laximo через внутренний сессионный сервис oem-catalog.rossko.ru, использовать его нельзя (https://github.com/DeepPealer/AvtoZapBot); вызывать API только по https и только с сервера. Условия оплаты, политика возврата (14 дней, по согласованию, в целой упаковке, электрика со следами установки не принимается), бесплатная доставка и адреса в Оренбурге — непроверены, запросить у менеджера письменно.

Резервные поставщики с API, подтверждённым по коду: Berg (REST api.berg.ru), Авто-Евро (https://api.autoeuro.ru/api/v2/json, числа приходят строками), Форум-Авто, Армтек (Basic-auth), Шате-М (Bearer) (https://github.com/EvgeniBondarev/Supplier-Quotation-Api). Emex для B2B — SOAP ws.emex.ru с логином/паролем в модели «оптовик → его потребители»; пороги подключения (баланс 30 000 ₽ или закупки 100 000 ₽ за 30 дней) непроверены (https://github.com/xkennich/emex-soap-client). У Autodoc публичного API нет: интеграции 2026 г. идут через приватный webapi.autodoc.ru и для коммерческого сервиса непригодны (https://github.com/pashokitsme/adoc).

## 2. VIN-каталоги и build vs buy

Ядро магазина (артикул → цена/наличие/срок/кроссы → заказ → статусы) полностью закрывается Rossko API без каталожных лицензий; подбор по VIN — отдельный источник. Laximo тарифицируется за запрос; кроме SOAP есть REST Guayaquil v3.0 (февраль 2026) и Laximo.Search со строкой «фильтр масляный <VIN>» — готовый сценарий для бота, пакетные вызовы до 5 команд снижают стоимость (https://github.com/laximo/guayaquillib_rest, https://github.com/laximo/search); тарифы (Starter 14 750 ₽ … Gold 414 375 ₽, «3 ₽ за VIN») непроверены. acat.online: VIN-поиск по REST, токен через sales@autodealer.ru, тарифы по лимитам запросов, обязательный запрет индексации каталога (https://github.com/AutoDealerRu/catalog-api-documentation). PartsAPI (VINdecode, getPartsbyVIN, getSearchTree) и apipoint работают, цены непроверены (https://github.com/xvexit/parts_bot). TecDoc легально в РФ недоступен — все «TecDoc 2025» идут через посредников. ABCP имеет публичный API ({id}.public.api.abcp.ru, md5-пароль, клиентский доступ через менеджера и статический IP) (https://pypi.org/project/aioabcpapi/); цены платформ (ABCP 10–62 тыс ₽/мес, Zaptrade 10–15 тыс, Parts-Soft 10–21 тыс, Docpart 22–50 тыс разово, GOODVIN от 7,6 тыс) непроверены. ZZAP как канал продаж и источник рыночных цен: b52-api.zzap.pro, заголовок zzap-api-key, не чаще 1 запроса в 3 с (https://github.com/akuto212/chatwoot-zzap-integration). Вердикт: свой бэкенд на Rossko API, VIN через Laximo.Search/PartsAPI/acat или ручной подбор, каталожные данные кэшировать и закрывать от индексации.

## 3. Платёжка и касса

Страницы тарифов не открылись: ставки ЮKassa (карты от 2,8%, СБП 0,4–0,7%), Т-Кассы (1,99–2,69%), Robokassa (3,9→2,9%), облачных касс (745–3 860 ₽/мес) взяты из обзоров и требуют сверки; промо 2,8% ЮKassa — только для новых ИП с 28.01.2026 по 01.12.2026 (https://github.com/groshevaon1-dotcom/terranova, вторично). По официальным SDK подтверждено: ЮKassa — полные и частичные возвраты, двухстадийный платёж capture=false с частичным подтверждением (срок холда «зависит от способа», 6 ч–7 дней непроверено), чек зачёта предоплаты через POST /receipts с settlements type=prepayment (https://github.com/yoomoney/yookassa-sdk-php/blob/master/docs/examples/04-receipts.md); актуальный Python SDK — PyPI yookassa 3.12.1. Robokassa — второй чек sendSecondCheck, холд только по картам (https://github.com/Robokassa/sdk-php). По 54-ФЗ исключений для АУСН нет, СБП от физлица тоже требует ККТ; в теге 1055 ФФД 1.2 кода АУСН нет — указывать «УСН доход», в позициях «без НДС»; при предоплате два чека: 1214=1 «предоплата 100%» при оплате и 1214=4 «полный расчёт» с зачётом (тег 1215) при выдаче — второй пробивает продавец, то есть ИП Максима, поэтому Лёше нужен доступ к кассе из админки. Telegram Bot API 10.3 для физических товаров требует provider_token из @BotFather, статус ЮKassa как провайдера непроверен (https://github.com/PaulSonOfLars/telegram-bot-api-spec); в MAX Bot API платежей нет. Надёжный путь — одна платёжка на сайте (ссылка/QR), вебхук в бэкенд, уведомления в оба мессенджера.

## 4. АУСН, ОКВЭД, раздел прибыли

Параметры АУСН — 8% «доходы» / 20% «доходы минус расходы» (минимум 3%), лимит 60 млн ₽, до 5 работников, месячный период, эксперимент до 31.12.2027 — по памяти модели: 17-ФЗ и закон Оренбургской области (№ 1292/547-VII-ОЗ от 29.11.2024, номер из сниппета) не открылись. Арифметика подтверждена: 8% берётся со всей выручки — при наценке 28% на закупку 100 налог 10,24, чистая наценка 17,76 (13,9% выручки); на объекте 20% налог 5,6 (4,4% выручки), точка равенства — наценка ≈67%; сменить объект можно только с 1 января, уведомив до 31 декабря. Запрет посредничества с 2025 г. действует только для агента, принципал допустим (номер пункта ч. 2 ст. 3 сверить): оферта — купля-продажа от имени ИП Максима, а приём денег за установку с передачей Лёше делает Максима агентом Сервис56 и ломает АУСН — установку оплачивают Сервис56 напрямую либо Максим продаёт её как свою услугу с субподрядом и 8% с неё. Возвраты покупателю уменьшают доход месяца возврата; возврат денег от Rossko — не доход, разметка «не учитывать» в ЛК до 7-го числа; доходы мимо ККТ вносятся до 5-го. Счета — только в уполномоченных банках (реестр на ausn.nalog.gov.ru).

ОКВЭД: 45.32.21 + 47.91.2, при опте 45.31.1; 45.20 — Сервис56. Форма Р24001 через ЛК ИП с УКЭП, Госуслуги, МФЦ или банк, пошлина 0 ₽, 5 рабочих дней; внести в течение 7 рабочих дней с начала деятельности (штраф по ст. 14.25 КоАП 5 000–10 000 ₽); главный риск — комплаенс 115-ФЗ (платформа ЦБ «Знай своего клиента» работает с 01.07.2022), код добавить до первого поступления.

Раздел 50/50: простое товарищество на АУСН и УСН «доходы» запрещено; НПД Лёше несовместим с его ИП; ООО 50/50 дороже (зарплата директора от МРОТ, НДФЛ 13%/15% с дивидендов). Рабочие варианты — договор услуг ИП↔ИП (приёмка, хранение, выдача, возвраты) с ежемесячными актами либо Лёша как агент Максима; при патенте Лёши на ремонт такие услуги требуют параллельной УСН (6% по умолчанию). АУСН освобождает от фиксированных взносов ИП (57 390 ₽ в 2026, по памяти); УСН с 2026 г. платит НДС с 20 млн ₽ дохода — аргумент вести обороты через Максима; входной НДС 22% в цене Rossko невозвратен. Вывод на личную карту — только на свой счёт с назначением «перевод собственных средств ИП», без обнуления счёта в день поступления.

## 5. Права потребителей, 152-ФЗ, маркировка

Дистанционная продажа (ст. 26.1 ЗоЗПП, ПП № 2463; нормы — по памяти модели): отказ до передачи и 7 дней после, без письменной памятки при передаче — 3 месяца; деньги в 10 дней за вычетом только фактических расходов на обратную доставку; отказать нельзя лишь по товару с индивидуально-определёнными свойствами, каталожная деталь по VIN им не является; Перечень невозвратных товаров к дистанционной торговле не применяется, поэтому «электрика и свечи не возвращаются» у Emex/Autodoc — политика магазинов, а не закон. Ст. 23.1: просрочка передачи предоплаченного товара — 0,5% предоплаты в день; брак — ст. 18, 22, неустойка 1%/день. Перед Rossko ИП — B2B-контрагент без защиты ЗоЗПП. На сайте и в боте обязательны реквизиты ИП, оферта, политика ПД, согласие на ПД отдельным документом (156-ФЗ, с 01.09.2025 — подтверждено цитатой публикации), cookies как ПД, чеки. Уведомление в РКН — до запуска; штраф за неуведомление с 30.05.2025 — 100–300 тыс. ₽ для юрлиц, по ИП верификаторы разошлись (как юрлицо либо 30–50 тыс.) — проверить примечание к ст. 13.11; утечки — от 3 млн ₽; локализация БД (ч. 5 ст. 18, с 2015 г.) — 1–6 млн ₽ (https://raw.githubusercontent.com/ZharovVsevolod/law_rag/master/data/docs/152/clean.md); запрет входа через иностранные сервисы с 07.07.2026 (ст. 13.55 КоАП, непроверено). Маркировка: шины обязательны (ПП 1958); масла, антифризы, тормозные жидкости — поэтапно в 2025–2026 (01.04.2026 для ККТ непроверено); автозапчасти (фильтры, свечи, стёкла, колодки, диски) — эксперимент с 25.02.2025, даты 31.08/01.09/01.12.2026 непроверены; аккумуляторы в перечнях не найдены; санкции — ст. 15.12 КоАП с конфискацией.

## 6. Боты MAX и Telegram

MAX подтверждён официальной OpenAPI-схемой 0.0.33 (https://github.com/max-messenger/api-schema): бот создаётся через MasterBot, но только ИП/юрлицам после верификации на business.max.ru и модерации; запросы на platform-api2.max.ru с сертификатом Минцифры (с июня 2026); для production — только webhook на HTTPS/443 с доверенным сертификатом (с 25.05.2026), секрет 5–256 символов в заголовке X-Max-Bot-Api-Secret, ретраи до 8 часов, успех — только 200 (отвечать сразу, обрабатывать в очереди); long polling — 2 запроса/с, хранение 24 часа, «не для production». Deep link до 128 символов, текст 4000, 7 типов inline-кнопок (reply-клавиатур нет), request_contact даёт телефон одним нажатием; GET /chats удалён — user_id сохранять из bot_started; лимиты отправки не опубликованы (только 429); платежей нет; мини-приложения через st.max.ru/js/max-web-app.js, initData проверяется HMAC-SHA256 с ключом «WebAppData» как в Telegram (https://github.com/instrumentburg-sudo/max-miniapp). SDK: @maxhub/max-bot-api 1.0.1, maxapi 1.2.2 (Python ≥3.10), maxo 0.9.0 (Python ≥3.12, сертификат вшит); swagger менялся примерно раз в 2–4 недели (https://github.com/K1rL3s/maxo). Telegram: Bot API 10.3, aiogram 3.31.0, grammY 1.46.0; deep link 64 символа; лимиты ~30/с и ~20/мин в группу неофициальны (https://github.com/python-telegram-bot/python-telegram-bot/wiki/Avoiding-flood-limits); вход — бесплатный request_contact или OIDC-вход oauth.telegram.org со scope phone и telegram:bot_access (вторичные источники); Telegram Gateway и SMS — платные фолбэки, цены непроверены. Замедление Telegram в РФ с 10.02.2026 и аудитория MAX непроверены. Единой библиотеки TG+MAX на Python нет — тонкий адаптер над aiogram и maxapi/maxo.

## 7. Рынок Оренбурга и доверие

Локальные данные непроверены: 4 точки Rossko (Шоссейная 28 к1; Харьковская 32; Хабаровская 52; Диагностики 2А), ~5 ПВЗ Emex, магазин Autodoc на Автомобилистов 2/2 — сверить на orenburg.rossko.ru/points-sale/ и в 2ГИС. Структурные выводы устойчивы: Rossko сам торгует в розницу в городе, и покупатель сравнит ваш ценник с его; конкуренты — Emex и Autodoc с большим ассортиментом, а не Ozon/WB; отличие возможно только в установке, подборе, живом ответственном лице и честных сроках. Слабости конкурентов по отзывам (удержание ~20% при возврате у Emex, расхождение статусов и дат, 100% предоплата у Autodoc) непроверены, но фиксированное удержание закону не соответствует — ваш аргумент «возврат без удержаний при самовывозе». Реальные условия доставки и оплаты вашего аккаунта возвращает GetCheckoutDetails. О «Сервис56» не найдено ни одного верифицируемого источника; контрафакт на маркетплейсах, факторы доверия и типичные наценки не исследованы — для проверки конкурентности +28% нужны 5–10 реальных строк заказов Лёши.

## Противоречия в исходном запросе

1. «Скопировать функционал Rossko: весь ассортимент и поиск по VIN» — API Rossko не отдаёт ни VIN-подбор, ни фото, ни описания; «весь ассортимент» не выгружается, каталог живой по запросу; парсинг сайта нарушает соглашение и грозит блокировкой основного поставщика; VIN легально только через лицензию (Laximo/acat) или ручной подбор.
2. «Наценка 28%, из них 8% — налог» — АУСН 8% считается от всей выручки, а не от наценки: на закупку 100 налог 10,24, чистая наценка 17,8% (13,9% выручки), а не 20%; дальше минус эквайринг ~3%, возвраты и доля Лёши. При такой наценке объект «доходы минус расходы» 20% почти вдвое дешевле.
3. «Если не понравится — просто возвращаем от своего имени» — возврат поставщику не бесплатен и не гарантирован: перед Rossko вы B2B-контрагент без ЗоЗПП, срок (14 дней, непроверено) считается от вашей покупки, возврат только по согласованию, электрика со следами установки не принимается, доставку платит возвращающий; клиент же вправе отказаться 7 дней (3 месяца без письменной памятки), а деньги вы обязаны вернуть за 10 дней независимо от Rossko.
4. «Делим 50/50» без юридической формы — простое товарищество запрещено на АУСН и на УСН «доходы»; переводы с личной карты Максима — незадекларированный доход Лёши и триггер 115-ФЗ для обоих; нужен договор услуг ИП↔ИП или агентский договор, где Лёша — агент Максима.
5. «Проводить как оплату автосервису» — работает только как оплата реальных услуг (приёмка, хранение, выдача, возвраты) по договору и акту; фиктивные услуги — риск; а если сайт принимает оплату установки и передаёт её Лёше, Максим становится агентом Сервис56 и теряет право на АУСН.
6. «Мы лишь спекулянты» противоречит статусу продавца по ЗоЗПП: 10 дней на возврат денег, неустойка 0,5%/день за просрочку передачи предоплаченной детали, претензии по браку до 2 лет, обязательные ККТ и два чека, уведомление РКН, локализация ПД, маркировка — ответственность у вас, а не у Rossko.
7. Rossko одновременно основной поставщик и прямой конкурент: он сам торгует в розницу в Оренбурге (точки с розничными часами, непроверено), покупатель сравнит ваш ценник с его; +28% поверх опта может оказаться выше розницы Rossko, Emex и Ozon — конкурентность не проверена ни на одной позиции.
8. «Телеграм как основной канал» — замедление Telegram в РФ (непроверено) делает его ненадёжным, а MAX требует верификации ИП и модерации бота, не имеет платежей и меняет API каждые 2–4 недели; «довести ботов до идеала» невозможно без постоянного бюджета на сопровождение.
9. «Платёжка на ИП» при «не знаю, как добавить ОКВЭД» — ОКВЭД 45.32.21/47.91.2 и уведомление в РКН нужны до первого поступления, иначе банк по 115-ФЗ запросит документы и ограничит ДБО; штраф за неуведомление РКН до 300 тыс ₽.
10. «Заказываем на свой адрес» — не определено, чей это адрес и чей аккаунт Rossko: адрес доставки и реквизиты привязаны к аккаунту (GetCheckoutDetails); если покупает Лёша, а продаёт Максим — Максим посредник (запрет на АУСН) и путаются чеки на выдачу.
11. «Люди заказывают на Ozon/WB и получают некачественное» — гипотеза без данных; реальные конкуренты в Оренбурге — Emex, Autodoc и розница самого Rossko с большим ассортиментом; доверие придётся доказывать фактами (бренды, фото, установка, честный возврат, реквизиты), а не тезисом о маркетплейсах.
12. «Всё, что есть на реальном сайте поставщика» и «подтянуть от Emex/Autodoc» — B2B-функции (кредитный лимит, ЭДО, волны доставки) клиенту не нужны, у Autodoc нет публичного API, у Emex пороги подключения, скрейпинг обеих площадок — юридический и технический риск; для соло-разработчика это scope creep, MVP должен строиться только на Rossko API плюс один резервный поставщик с API.

## Юнит-экономика

Пример: деталь 10 000 ₽ по опту Rossko (цена уже с НДС 22%, для АУСН невозвратным). Цена клиенту при +28% — 12 800 ₽. АУСН 8% считается от выручки: 1 024 ₽ (а не 800 ₽ «от наценки»). Эквайринг 2,5–3% от 12 800 ₽ — 320–384 ₽ (карты с НДС на комиссию ≈3,4% → 435 ₽, СБП 0,7% → 90 ₽; в расчёте 352 ₽). Фиксированные расходы: инфраструктура ≈2 500 ₽ + облачная касса/ОФД ≈2 000 ₽ (цены непроверены) = 4 500 ₽/мес → 90 ₽ на заказ при 50 заказах и 23 ₽ при 200 (альтернатива «Чеки от ЮKassa» ~1%/чек — 128 ₽ за чек, возможно ×2 с зачётным). Возвраты 5%: по возвращённому заказу клиент получает 12 800 ₽ полностью (налог 1 024 ₽ восстанавливается в месяце возврата), комиссия эквайринга 352 ₽ не возвращается, у поставщика теряем предположительно ~15% себестоимости (1 500 ₽ — доставка туда-обратно и риск частичного отказа; реальные условия Rossko неизвестны) → 1 852 ₽ на один возврат, ожидание 93 ₽ на каждый проданный заказ; если Rossko деталь не примет (электрика, позже 14 дней) — потеря 10 352 ₽, ожидание 518 ₽/заказ.

| Показатель, ₽ на деталь | 50 заказов/мес | 200 заказов/мес |
|---|---|---|
| Выручка | 12 800 | 12 800 |
| Себестоимость | 10 000 | 10 000 |
| АУСН 8% | 1 024 | 1 024 |
| Эквайринг ~2,75% | 352 | 352 |
| Касса + инфраструктура | 90 | 23 |
| Ожидаемые потери на возвратах (5%) | 93 | 93 |
| Чистая маржа | 1 241 (12,4% от себестоимости, 9,7% выручки) | 1 308 (13,1%, 10,2%) |

В месяц до раздела ≈62 тыс ₽ при 50 заказах и ≈262 тыс ₽ при 200; по 50/50 — 31 и 131 тыс ₽ каждому (Лёша со своей половины платит ещё УСН 6%; на объекте «доходы» выплата Лёше базу Максима не уменьшает). Если поставщик не принимает возвраты, маржа падает до ≈816 ₽ (8,2%). На объекте АУСН 20% (с 2027): база 12 800 − 10 000 − 352 − 90 − 93 = 2 265 ₽, налог 453 ₽ (минимальный 3% = 384 ₽ меньше) → маржа ≈1 812 ₽ (18,1% от себестоимости) — на ≈570 ₽ больше на каждой детали, а выплаты Лёше и доставка ещё уменьшат базу. Не учтены: доставка от Rossko (бесплатность непроверена), VIN-подбор (Laximo за запрос), SMS и время на обработку заказа.

## Вопросы фаундеру и его решения

Ответы зафиксированы в docs/PLAN.md, раздел «Решения фаундера».

1. **Чей аккаунт Rossko будет «рабочим» для сайта и есть ли у него доступ к API (ключи KEY1/KEY2)?** Ключи привязаны к конкретному контрагенту: его скидке/прайс-колонке, адресам доставки и кредитному лимиту. Кто покупает у Rossko — тот юридически продавец клиенту. Если закупает ИП Лёши, а деньги на сайте получает ИП Максима, Максим превращается в посредника, что запрещено на АУСН, и ломается цепочка чеков и возвратов. Варианты: Новый оптовый аккаунт на ИП Максима + запрос ключей API у оренбургского менеджера; Аккаунт Лёши/Сервис56 и его ключи, Максим только принимает оплату; Два аккаунта: Максима — для сайта, Лёши — для закупок сервиса. Рекомендация: Новый аккаунт на ИП Максима: закупка и продажа в одном лице, чистая цепочка «оплата → чек → заказ у Rossko → возврат». У Лёши остаётся свой аккаунт для сервиса. Риск — худшая скидка у нового клиента, поэтому до запуска сравнить цены по 20–30 ходовым позициям между аккаунтами.
2. **100% предоплата на сайте или оплата при получении?** Перед Rossko вы B2B-покупатель без ЗоЗПП: невыкуп клиентом — замороженные деньги и риск непринятого возврата. Клиент же по ст. 26.1 вправе отказаться 7 дней. Холд ЮKassa ограничен по сроку. От ответа зависит схема чеков (предоплата + зачёт vs один чек) и конверсия. Варианты: 100% предоплата на всё; Предоплата только на позиции «под заказ», при наличии на оренбургском складе — оплата при выдаче; Частичная предоплата 30–50%; Оплата при получении на всё. Рекомендация: Гибрид: позиции со склада в Оренбурге (по полю склада в GetSearch) — оплата при выдаче через СБП-QR/терминал одним чеком, позиции под заказ — 100% предоплата с двумя чеками. Это баланс конверсии и риска «зависших» деталей.
3. **Авто-заказ у Rossko через GetCheckout сразу после оплаты или ручное подтверждение продавцом?** GetCheckout может вернуть itemErrors уже после того, как клиент заплатил; цены и сроки меняются между поиском и оплатой; ошибки VIN-подбора и лимиты API. Полная автоматика без контроля создаёт возвраты и недовольство, полная ручная работа — то, от чего Лёша хочет уйти. Варианты: Полный авто-заказ после подтверждения оплаты; Полуавтомат: заказ собирается, продавец подтверждает кнопкой в боте в течение N часов после предпроверки GetSearch; Всё вручную в ЛК Rossko. Рекомендация: Полуавтомат на MVP: кнопка «Заказать у поставщика» в боте продавца с автоматической перепроверкой цены/наличия и обработкой itemErrors; через 1–2 месяца статистики включить полный автозаказ для позиций без VIN-подбора.
4. **VIN-подбор на старте: лицензия каталога (Laximo/acat) или ручной подбор менеджером?** В API Rossko VIN нет; Laximo платный за запрос и требует договора; ошибки подбора оборачиваются возвратами, которые Rossko (непроверено) принимает только если подбирали его менеджеры. Это самая дорогая и рискованная часть «скопировать функционал». Варианты: Laximo.CAT/Laximo.Search с первого дня; acat.online или PartsAPI как дешёвый слой VIN → артикулы; MVP: поиск по артикулу + кроссы Rossko + форма «пришлите VIN и фото — подберём» (Лёша/биржа подбора); Без VIN вовсе. Рекомендация: Вариант с ручным подбором на MVP: он бесплатен, усиливает доверие («живой человек проверил») и даёт статистику, сколько заявок приходят с VIN без артикула; по ней решить, окупится ли Laximo.Search или acat во второй фазе.
5. **География и выдача: только самовывоз из Сервис56, курьер по Оренбургу или ТК по России?** Определяет оферту и сроки (ст. 23.1 — 0,5%/день за просрочку), момент второго чека (курьер/ТК), конкуренцию с ПВЗ Emex/Autodoc и необходимость интеграций с доставкой. Дистанционный возврат из другого города убивает маржу. Варианты: Только самовывоз из Сервис56 с возможностью установки; Самовывоз + курьер по Оренбургу; Плюс транспортные компании по области/РФ. Рекомендация: Самовывоз плюс курьер по городу на MVP; ТК — не раньше, чем отлажены возвраты и предоплата, потому что иногородние возвраты и споры по ЗоЗПП съедят наценку.
6. **Какой налоговый режим у Лёши/Сервис56 и как юридически оформить 50/50?** Простое товарищество запрещено на АУСН и на УСН «доходы»; агентирование в пользу Сервис56 ломает АУСН Максима; переводы с личной карты — незадекларированный доход Лёши и триггер 115-ФЗ. Патент на ремонт не покрывает услуги логистики/приёмки — нужна параллельная УСН. Варианты: Договор возмездных услуг ИП↔ИП (приёмка, хранение, выдача, возвраты, подбор) с ежемесячным актом; Лёша — агент Максима за процент от заказов (принципал на АУСН допустим); ООО 50/50; Неформальные переводы. Рекомендация: Договор услуг ИП↔ИП с актами, если Лёша на УСН (при патенте — добавить УСН). Это дешевле ООО, даёт первичку обеим сторонам и понятное назначение платежей; неформальные переводы исключить.
7. **Установка в сервисе — часть заказа на сайте или отдельная сделка Сервис56?** Если сайт принимает деньги за установку и передаёт их Лёше, Максим становится агентом Сервис56 и теряет право на АУСН. Альтернативы: Максим продаёт установку как свою услугу (8% и с неё, субподряд) либо клиент платит Сервис56 напрямую. Варианты: На сайте только запчасть; установку клиент оплачивает в сервисе Лёше по его чеку; «Запчасть + установка» одним заказом как услуга Максима с субподрядом Сервис56; Кнопка «записаться на установку» без оплаты на сайте. Рекомендация: Запчасть через сайт, запись на установку в боте без оплаты, оплата установки в Сервис56 напрямую. Чисто по АУСН и 54-ФЗ, Лёша сохраняет свою выручку от работ.
8. **Исключать ли на старте шины, масла, антифризы и тормозные жидкости из каталога?** Шины уже под обязательной маркировкой, масла и жидкости вводятся в 2025–2026: нужны УКЭП, ЭДО с поставщиком, ККТ с передачей кодов и разрешительным режимом; штрафы по ст. 15.12 КоАП с конфискацией. Фильтры, свечи, колодки, диски — пока эксперимент. Варианты: Исключить маркируемые группы на старте фильтром по товарным группам Rossko; Продавать их только как расходник в составе услуги установки Сервис56; Подключить «Честный знак» сразу. Рекомендация: Исключить на старте, но заложить в БД поле кода маркировки и готовность к ЭДО; пересмотреть к концу 2026 года, когда прояснится статус автозапчастей.
9. **Какой мессенджер основной для клиентов — MAX или Telegram, и в каком живёт бот продавца?** Замедление Telegram в РФ не подтверждено, но вероятно; MAX требует верификации ИП и модерации бота (дни), его API нестабилен (изменения swagger каждые 2–4 недели), платежей нет ни там, ни там без провайдера. Реальная база — последние 30–50 заявок Сервис56. Варианты: Telegram основной, MAX второй; MAX основной, Telegram второй; Оба равноправно через общий адаптер с первого дня; Сайт + SMS/e-mail, боты позже. Рекомендация: Решить по опросу клиентов Лёши; по умолчанию оба через тонкий адаптер (aiogram + maxapi/maxo), клиенту — тот канал, где он подписался, уведомления продавцу — в Telegram-чат (так делают даже MAX-first бизнесы).
10. **В каком банке расчётный счёт ИП и какую связку «платёжка + касса» выбираем?** Банк обязан быть в реестре АУСН; эквайринг с НДС 22% на комиссию; второй чек при выдаче должен пробивать ИП Максима; «Чеки от ЮKassa» снимают возню с ККТ, но стоят ~1%/чек (непроверено) — при росте оборота выгоднее своя облачная касса с банковским эквайрингом. Варианты: ЮKassa + «Чеки от ЮKassa» (одна интеграция, СБП, чек зачёта по API); Банковский эквайринг (Т-Касса/Модульбанк) + своя облачная касса; Robokassa + Робочеки. Рекомендация: ЮKassa на старте: быстрее всего по 54-ФЗ и одинаково работает для сайта, Telegram и MAX; пересмотреть при обороте выше 500–700 тыс ₽/мес. До договора сверить все ставки на сайтах и спросить ЮKassa, тарифицируется ли зачётный чек отдельно.
11. **Какую политику возврата обещаем клиенту?** Условия Rossko (B2B, 14 дней по согласованию — непроверено) не компенсируют ваши обязательства по ст. 26.1; категорийные запреты «электрика не возвращается» юридически уязвимы; честный возврат без удержаний — ваш главный аргумент против Emex. Варианты: Ровно по ЗоЗПП: 7 дней, без следов установки, без удержаний при самовывозе; Расширенный возврат 14 дней как маркетинг; Попытка ограничить возврат деталей, «подобранных по VIN клиентом». Рекомендация: Ровно по ЗоЗПП плюс письменная памятка при выдаче (иначе срок отказа растёт до 3 месяцев), осмотр и фотофиксация при передаче. Ограничения через категории не вводить — это проигрышная позиция в Роспотребнадзоре.
12. **Бренд и домен: под именем Сервис56, новый бренд или гибрид, и кто продавец в глазах клиента?** Реквизиты ИП Максима обязаны быть на сайте; домен .ru с 01.09.2026 требует ЕСИА-идентификации администратора; бот MAX требует верифицированный бизнес-профиль; доверие в Оренбурге строится на известности сервиса, а не нового сайта. Варианты: «Сервис56 Запчасти»: бренд сервиса, продавец — ИП Максима; Новый независимый бренд; Полностью под Сервис56 (тогда продавец — Лёша). Рекомендация: Гибрид: узнаваемость Сервис56 в бренде и на точке выдачи, юридически продавец — ИП Максима; домен на ИП Максима с привязкой Госуслуг сразу при регистрации.
13. **Какой бюджет в месяц допустим и сколько заявок/какой средний чек сейчас у Лёши?** Определяет build vs buy (ABCP/Zaptrade 10–60 тыс ₽/мес против своего стека за 2–3 тыс), оправданность Laximo, SMS-фолбэка и второй среды; без цифр юнит-экономика и выбор платёжки остаются гипотезами. Варианты: До 5 тыс ₽/мес — всё своё на одном VPS; 5–15 тыс ₽/мес — плюс VIN-каталог и SMS; 15–60 тыс ₽/мес — готовая платформа.
